# 单词学习台 · Vocab Lab

本地网页端背单词工具，支持导入 **Excel / CSV 单词表**。纯前端，数据全部保存在本机浏览器里。

## 快速开始

```bash
cd vocab-app
npm install
npm run dev
```

浏览器打开 <http://127.0.0.1:5180>。

> 也可以直接双击 `start.sh`（macOS）。

## 核心功能

| 功能 | 说明 |
| --- | --- |
| 多词库 | 「词库」页用卡片展示所有词库，点击卡片进入单词列表；卡片上可重命名 / 删除 / 导入，也可新建词库；学习、复习、统计和导入都只针对当前词库 |
| Excel 导入 | 拖入 `.xlsx / .xls / .csv` 单词表，导入到**当前词库**：**第一列单词、第二列释义、第三列音标（可选）**，表头行自动跳过，重复单词不新增（缺音标的旧词会补上音标） |
| 新词库 | 所有新导入的单词进入新词库，等待学习 |
| 复习库 | 标记「认识」的单词先计入「已掌握」，按间隔阶梯（首次间隔默认 2 天，之后 4 / 7 / 15 / 30 / 60 / 90 天）到期后自动进入复习队列；标记「不认识」的直接进入今日复习队列 |
| 复习模块 | 顶部「复习」页只展示**今天进入复习队列**的单词，可分页浏览、点击朗读，一键开始只复习的一轮 |
| 听写模式 | 复习页「听写模式」：先听发音再把单词写出来，每词 3 次机会；写对或 3 次用完都会展示单词 / 音标 / 释义（写对 → 已掌握，写错 → 留在今日复习队列） |
| 每日随机 | 每天按设定数量从新词库、今日复习队列中**随机抽取**，打乱混合成一轮学习 |
| 复习判定 | 三档：**认识**（阶段 +1，按阶梯安排下次）、**模糊**（阶段不动，明天再来一次）、**不认识**（阶段回退两档，今天继续考）；可用 `u` 撤销上一次判定 |
| 相近词 | 学习卡片答完后展示三组对照：**形近词**（编辑距离判定的易混拼写，如 adapt / adopt）、**同词根词族**（共前缀或后缀，如 produce / reduce）、**释义相近**（本词库内中文释义重合的词） |
| 易错本 | 词库页「易错」筛选，列出答错 ≥ 2 次的单词（「模糊」也计入错误次数），按错误次数排序 |
| 今日记录 | 「今日」页按「新学 / 复习」两个 tab 分开展示，支持分页查看当天全部记录 |
| 复习归类 | 词库可随时按「新词库 / 复习库 / 已掌握」筛选；已掌握 = 学过且认识、还在等待进入复习队列的单词 |
| 发音 | 使用 kokoro-js 在本机离线合成英文发音，模型随项目加载；加载失败自动回退系统语音 |
| 造句练习 | 顶部「造句」页，**与词库无关**的独立练习：DeepSeek 按主题和难度实时出一句中文，你写英文，它按「意思准确 60 + 语法 25 + 地道 15」打分，返回修正句、参考译文和最多 3 条问题说明 |
| 造句记录 | 做过的句子（题面、我的译文、修正、参考译文、分数）自动存在本地，可展开回看、单条删除或清空；出题时会避开最近做过的句子 |
| 阅读 | 顶部「阅读」页：文章自动标出**词库里出现过的词**（琥珀色＝还没掌握，灰色＝已掌握），点任意单词看释义、听发音，再一键把文中这些词组成一轮学习集；词形会还原（running → run） |
| DailyRead 每日阅读 | 阅读页顶部的每日文章卡：**按四六级命题思路现写一篇**（不是抓现成词条），自选**四级（约 300 词）/ 六级（约 400 词）**，可选主题（科普 / 教育 / 心理 / 环境 / 科技 / 商业 / 健康 / 文化，或自己填），留空则随机。一篇文章**自带 5 道四选一**（主旨 / 细节 / 词义 / 推断 / 态度），点「开始阅读」即可边读边做；当天同难度只生成一次，之后再进秒开，「换一篇」重新写 |
| 往期 | 生成的每篇文章自动留档（最多 40 篇），「查看往期」点任意一篇重读。**AI 精读、逐段译文、题目与你的作答都存在这篇文章的记录里**，列表上有「解析 / 译文 / 题」标记，点开原样恢复（译文直接展开对照，题目保留上次选项）；另附 10 个分级网站清单，想读真实外刊时自己去逛 |
| AI 精读 | 文章页点「✨ AI 精读」，DeepSeek 会给出中文标题、主题标签、一句话导读、3~6 个生词（含音标与释义，可一键加进词库）以及一句长难句解析；中文标题会自动回填到 DailyRead 卡片上。需要先填 API Key，同一篇只花一次 token；结果存在往期记录里，下次点开还在 |
| 段落卡片与翻译 | 文章按自然段拆成独立卡片（每段仍保留标词高亮）；每段右下角有「译」按钮，第一次点会一次请求翻好全篇（按段缓存，同一篇不重复花 token），再点「🌐 全部译文」可展开全部段落对照阅读 |
| 阅读理解 | 每日文章自带 5 题，打开即可做；也可以点「📝 阅读理解」让 DeepSeek 另出一批（或「换一批题」）。本地判分：选对绿色、选错红色并标出正确答案，附中文解析；做完可「重做」 |
| 音标 | 使用导入的第三列音标，显示在学习卡片、词库列表、今日记录和复习列表 |
| 备份 | 设置页可导出 / 导入 JSON 备份 |

## 使用流程

1. **词库**：词库页以卡片展示各词库，点卡片进入该词库的单词列表；卡片上可重命名、删除、导入，点「＋ 新建词库」可创建新的词库。
2. **导入**：把 Excel 单词表（如 `单词释义表.xlsx`）拖到导入页 → 检查预览 → 确认导入，单词会进入当前词库。
3. **今日**：点「开始今日学习」，卡片先显示单词，按 `空格` 显示释义，再按 `1` 认识 / `3` 模糊 / `2` 不认识；判定错了按 `u` 撤销。卡片上的音标可点击修改；右侧「学习词库」下拉可直接切换。
4. **单词列表**：在卡片上点「查看单词」进入，可搜索、筛选（含「易错」）、把某个单词放回新词库或删除。
5. **复习**：只列出今天进入复习队列的词，可分页浏览、朗读；点「开始复习」按卡片复习，或点「听写模式」先听发音再默写（每词 3 次机会）。
6. **造句**：顶部「造句」页选主题（日常 / 工作 / 观点…）和难度（入门 / 进阶 / 挑战），点「出题」由 DeepSeek 现场生成一句中文，
   写出英文后按 `⌘/Ctrl + Enter` 提交，得到分数、AI 修正、参考译文和问题清单；做完的句子自动进「做过的句子」列表。
   需要先在设置里填 API Key，题目不预置、不落题库，只保留已完成的记录。
7. **阅读**：进「阅读」页，顶部 DailyRead 卡片会自动生成今天的一篇（四级 / 六级可切换，可填主题），
   点「开始阅读」后文章按自然段显示成卡片，词库里的词会标色；点词看释义 / 听发音。
   文章自带 5 道阅读理解题，滑到底部直接做，选完立刻判分并给中文解析。
   想更细就点「✨ AI 精读」（中文标题、导读、生词、长难句），或「🌐 中文翻译」逐段对照。
   读完后右下角「生成学习集」把这篇文章里的词组成一轮学习。
8. **设置**：调整每日新词数（默认 20）、每日复习数（默认 30）、首次复习间隔（默认 2 天）、
   卡片方向；在「发音」面板选择 Kokoro 音色或切回系统语音，并可试听；「AI 造句练习」面板填写 DeepSeek API Key。

### 快捷键

| 按键 | 作用 |
| --- | --- |
| `空格` | 显示释义 |
| `1` | 认识 |
| `2` | 不认识 |
| `3` | 模糊 |
| `u` | 撤销上一次判定 |

## 导入规则

- 第一列作为单词，第二列作为释义，第三列作为音标（可写 `/ˈæpl/` 或直接写 `ˈæpl`），其余列忽略。
- 每个工作表都会读取，多表自动合并去重。
- 首行如果是「单词 / 释义」「Word / Meaning」这类表头，会自动跳过。
- 单词按小写去重；同一单词已存在时不新增（若旧词缺音标且这次第三列有值，会补上音标）。

## 注意

- 数据存在浏览器 IndexedDB 中，换浏览器 / 清理缓存会丢失，请在设置页导出备份。
- 复习计划基于本机日期，跨时区无需处理。
- Kokoro 模型约 90MB，已放在 `public/models/kokoro/`，无需联网；首次加载需要几秒，
  加载期间或失败时会自动回退系统语音。若只想轻量使用，可在设置里切回「系统语音」。
- 单次合成要 1~2 秒，所以卡片出现时就会在后台预生成当前词（以及下一张卡）的音频并缓存，
  点 🔊 基本立刻出声；只有刚出卡就马上点、或遇到新词时才需要等合成。
- 本地开发 / 预览的 `vite.config.ts` 带 `Cross-Origin-Opener-Policy`、`Cross-Origin-Embedder-Policy`
  头，让 onnxruntime 启用多线程（单线程会慢一倍）。改动该文件后需刷新页面（浏览器要重新加载才生效）；
  若用自己的服务器部署，也要配置这两个响应头。
- 构建产物 `dist/` 会一并包含模型文件，因此体积约 140MB，属于正常现象。
- 造句练习的 API Key 存在浏览器 localStorage（键名 `vocab-app.ai.key`），**不在** IndexedDB 状态里，
  因此导出备份不会带上它；换浏览器或清缓存后需要重填。请求从浏览器直连 `api.deepseek.com`，
  不经过任何中间服务器；练习记录同样只存本机。

## 部署到 GitHub Pages

仓库自带 `.github/workflows/deploy.yml`，推送到 `main` 会自动构建并发布。

**首次部署必须把构建源切到 Actions**：Settings → Pages → Build and deployment →
Source 选择 **GitHub Actions**（不要选 "Deploy from a branch"）。
如果仍用分支源，GitHub 会把仓库根目录当作站点，根目录的 `index.html` 是开发入口
（引用 `/src/main.ts`），打开只会白屏。

站点地址：`https://<用户名>.github.io/<仓库名>/`

注意事项：

- 仓库名不是 `<用户名>.github.io` 时，`vite.config.ts` 的 `base` 必须写成 `/<仓库名>/`，
  否则 JS / CSS 走绝对路径会 404，页面空白。
- `node_modules`、`dist` 不要提交（已在 `.gitignore` 里）。仓库里塞几百 MB 依赖会让
  Pages 自带的分支构建超时失败，表现为访问一直是 404 "Site not found"。
- GitHub Pages 不支持自定义响应头，拿不到 COOP/COEP，Kokoro 会退化为单线程
  （每词慢 2~3 秒）。线上更推荐在设置里改用系统语音。
- 首次访问要下载约 88MB 的语音模型，手机上不建议开启 Kokoro。
